# 🎬 MovieFlix

A modern movie discovery web application built with **React.js** and the **TMDB API**. Search for your favorite movies, explore trending titles, and save your favorites with a clean Netflix-inspired UI.

## ✨ Features

- 🔍 Search movies by title
- 🎥 Browse popular movies
- ❤️ Add & remove favorites
- 💾 Favorites stored using Local Storage
- ⚡ Fast and responsive UI
- 🌙 Netflix-inspired dark theme
- 📱 Mobile-friendly design
- 🎨 Modern animations and hover effects

## 🛠️ Tech Stack

### Frontend

- React.js
- React Router DOM
- JavaScript (ES6+)
- CSS3

### API

- TMDB (The Movie Database)

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/your-username/movieflix.git
```

Go to the project folder

```bash
cd movieflix
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open your browser

```text
http://localhost:5173
```

---

## 🔑 TMDB API Setup

Create a `.env` file in the project root.

```env
VITE_TMDB_API_KEY=YOUR_API_KEY
```

Get your API key from:

https://developer.themoviedb.org/
